# Music Home v1.1.1 - Direct Access Update 🎶🛡️

Music Home continues evolving into a dedicated Android DAP-style platform. This update focuses on giving users direct control over their music collections and improving the experience on legacy hardware.

## Highlights

### 🎵 Direct Access Library
- Added manual folder selection for music libraries.
- Recursive folder scanning support.
- Better handling of local offline collections.

### 🎨 Artwork & Library Improvements
- Persistent album artwork caching (512px JPGs).
- Faster library loading and smoother scrolling.
- Improved album and artist browsing experience.

### 🎚️ Audio Experience
- Advanced multi-band equalizer support.
- Real-time 16-band spectrum visualizer.
- Improved playback queue recovery and position persistence.

### 🛠️ Stability Improvements
- Fixed layout issues on portrait devices.
- Improved legacy hardware compatibility (Android 7.0+).
- Custom hardware volume HUD and key interception fixes.

## Recommended Devices

Android 7.0+ devices:
- **Old tablets**: Perfect for wall-mounted controllers.
- **Spare phones**: Distraction-free pocket players.
- **Android TV boxes**: Dedicated media hub appliances.
- **Dedicated music players (DAPs)**: A fresh OS feel for specialized hardware.

Music Home is designed to give unused hardware a second life. ⚡
